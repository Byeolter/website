WHY NANALI

편안한 순간에도,
세심한 구현이 필요하니까.

모바일 캐주얼·힐링 게임에 대한 관심을 가진 개발자를 찾는다는 나날이의 공고에서, 제가 만들고 싶은 경험과의 접점을 보았습니다.

스타듀밸리를 즐기다 게임 개발을 시작했고, 작은 펫을 돌보는 위젯버디를 만들었습니다. Unity 프로젝트에서 익힌 성능 개선과 협업 경험을 바탕으로, 일상 속에 자연스럽게 스며드는 플레이를 함께 만들고 싶습니다.

02 — HOW I BUILD

편안한 플레이를 만드는
보이지 않는 고민들.

실제 프로젝트에서 마주한 문제와
제가 선택한 해결 방법입니다.

WIDGET BUDDY / BACKGROUND STATE

실행 횟수보다, 실제로 흐른 시간.

WorkManager의 실행 간격을 가정하지 않고, 마지막 갱신 이후 실제 경과 시간으로 펫 상태를 계산했습니다. 계산한 상태는 DataStore에 저장해 앱과 위젯이 함께 사용하도록 했습니다.

실제 경과 시간→펫 상태 계산→앱 · 위젯 반영

APPLIED / TIMESTAMP + DATASTORE

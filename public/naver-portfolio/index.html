01

앱을 열지 않아도 이어지는 작은 친구의 하루.

프로젝트 이야기 ＋

2025.11 초기 개발 · 이후 개선
개인 프로젝트

앱을 열지 않아도 홈 화면에서 작은 펫을 돌볼 수 있는 게임입니다. 개인 프로젝트로 Kotlin 앱과 위젯을 만들고 Google Play에 출시했습니다. 출시 후에는 백그라운드 실행이 늦어져도 실제로 흐른 시간에 맞춰 펫의 상태가 바뀌도록 갱신 방식을 개선했습니다.

제가 맡은 일

  • Jetpack Glance 기반 위젯 UI와 사용자 상호작용 구현
  • 마지막 갱신 시점과 실제 실행 시점의 차이로 펫 상태 계산
  • DataStore를 통한 앱·위젯 간 펫 상태 공유
  • Google Play 배포 및 이후 개선

문제와 해결

백그라운드 작업이 지연되면 실행 횟수만으로 펫 상태를 갱신할 때 실제 경과 시간과 차이가 생길 수 있습니다. WorkManager가 일정한 간격으로 실행된다고 가정하지 않고, 마지막 갱신 시점과 실제 실행 시점의 차이로 상태를 계산했습니다. 계산한 상태는 DataStore에 저장해 앱과 위젯이 함께 사용하도록 했습니다.

결과

  • 홈 화면 위젯 기반 펫 게임 출시
  • 백그라운드 실행 지연에도 실제 경과 시간에 맞춰 상태 반영
  • 앱·위젯이 동일한 저장 상태를 사용하는 구조 구현

프로젝트 이야기 ＋

2026.05.28–06.18 · 4주
4인 팀 · Android/iOS 앱 UI 구현, Supabase 연동

4명이 함께 만든 반려동물 IoT 앱입니다. 센서가 감지한 배변 기록을 보호자가 앱에서 확인할 수 있도록, 저는 Android/iOS 앱 UI와 Supabase 연동을 맡았습니다.

제가 맡은 일

  • Compose Multiplatform으로 Android/iOS 앱 UI 구현
  • Supabase와 연동해 배변 기록을 앱에서 조회·관리하는 화면 구현
  • 하드웨어·서버 담당 팀원과 앱에 연결되는 데이터 흐름 확인

문제와 해결

센서에서 기록을 보내는 것부터 앱에서 확인하는 것까지, 서로 맡은 작업이 이어져야 하는 프로젝트였습니다. 팀이 구성한 기기 등록 → 홈 요약 → 기록 목록 흐름에 맞춰 앱 UI를 구현하고 Supabase 데이터를 연결했습니다. 제가 맡은 화면을 완성하는 동시에, 다른 팀원의 작업과 맞닿는 부분을 확인하며 진행했습니다.

결과

  • 4주간 4인 팀으로 IoT 모니터링 앱 제작
  • 기기 등록부터 기록 조회·수동 관리까지 이어지는 앱 제공
  • Android/iOS 공통 UI와 데이터 연동 경험

03 / TypeScript

템플모아

03

직접 느낀 불편에서 시작한 템플스테이 서비스.

프로젝트 이야기 ＋

2026 · 운영 중
개인 프로젝트 · 기획·검증·운영

템플스테이 정보를 모바일에서 찾기 어렵다는 제 경험에서 시작했습니다. 필요한 기능을 기획하고, 코드는 Codex를 활용해 구현했습니다. 저는 실제 화면과 동작을 확인하며 수정 방향을 정하고, Web·iOS·Android 출시와 운영까지 진행했습니다.

제가 맡은 일

  • 일정 탐색·등록·알림·후기 등 필요한 기능과 요구사항 정리
  • Codex에 구현 요구사항과 수정 방향 전달
  • 모바일에서 실제 화면·동작을 확인하고 UI 개선 방향 결정
  • Supabase·Grafana로 사용자 유입과 이용 현황 모니터링

문제와 해결

처음 나온 화면은 웹 중심이라 모바일에서 사용하기 불편했습니다. 직접 화면과 동작을 확인하며 고칠 부분을 찾고, Codex에 수정 방향을 전달한 뒤 결과를 다시 확인했습니다. 출시 뒤에도 Supabase·Grafana로 사용자 유입과 이용 현황을 살피며 서비스를 운영하고 있습니다.

결과

  • Web·App Store·Google Play에 서비스 출시
  • 웹 중심의 초기 UI를 모바일 사용 흐름에 맞게 개선
  • 모니터링으로 사용자 유입과 이용 현황 확인
